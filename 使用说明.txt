名称提取工具 · Windows 免安装版

一、推荐用法
双击“名称提取工具.exe”，添加或拖入一个或多个文件夹。
选择“不带后缀”或“文件名＋后缀”，点击“开始提取”。
确认预览后，点击“复制全部”或“导出 TXT”。导出文件为 UTF-8（带 BOM），每行一个名称。
单独复制 EXE 到其他位置也能使用。不需要 Python、联网或管理员权限。
运行环境：Windows 10/11 桌面系统，自带 .NET Framework 4.x。

二、两种后缀模式
文件名                   不带后缀             带后缀
研究报告.docx            研究报告             研究报告.docx
archive.tar.gz           archive.tar          archive.tar.gz
README                   README               README
.gitignore               .gitignore           .gitignore
只去掉最后一段扩展名；名称中间的点号保留。

三、文件夹名称
“提取内容”可选：文件、子文件夹、文件和子文件夹。
文件夹名称始终完整保留，如“实验.v2”不会变成“实验”。
默认只扫描每个选定文件夹的直接内容；勾选“包括所有子文件夹”可递归。
默认不包含隐藏／系统项，可按需勾选。
递归时不进入符号链接、目录联接等链接文件夹，防止循环；详情会显示提示。
遇到无权访问的目录会显示提示，可点击“查看跳过详情”。

四、与图片相同的一键用法
将 EXE 和两个 BAT 一起复制到待提取文件夹，双击对应 BAT。
也可以把一个目标文件夹拖到 BAT 上，无须复制进目标文件夹。
每次生成新的“__名称提取_模式_时间.txt”，不会覆盖上一次结果。
BAT 默认只提取当前层的文件，不包括隐藏／系统文件和子文件夹名称。
需要提取文件夹名称或递归时，请使用 EXE 窗口。
BAT 适用于简体中文 Windows（脚本按 GBK 编码）。其他语言系统请使用 EXE。

五、细节
自动排除正在运行的 EXE，以及与它同目录的两个配套 BAT。
自动排除名称以“__名称提取_”开头且扩展名为 .txt 的结果文件。
其他文件正常参与提取（包括本说明文件，如放在待扫描目录）。
结果按名称排序；不同文件的同名结果保留，勾选“保留路径”可以区分。
一个文件在重复或重叠选择的文件夹中只计一次。
单一目录保留相对路径；选择多个目录时显示绝对路径，以区分来源。
预览最多显示 5000 项；复制和导出始终包含全部结果。
所有读取均在本机完成，不上传文件；只创建用户导出的 TXT。

六、开源方案检索与实现
参考了相似的开源方案 DirLister：
https://github.com/SanderSade/DirLister
它支持 TXT 等多种输出、拖放、隐藏文件和目录列表功能，采用 MPL-2.0。
本工具需求较小，采用系统自带 .NET Framework / Windows Forms 独立实现，
未复制 DirLister 源码，也不需要其依赖或安装资源管理器扩展。
项目根目录保留 NameExtractor.cs 和 build.ps1，便于后续修改和重新编译。
